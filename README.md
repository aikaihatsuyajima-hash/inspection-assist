# 検品アシスト

物流倉庫の出荷検品を想定した、インストール不要のブラウザアプリです。検証用PDFに掲載されたバーコードを、8つのオリコン・119品番のテストデータとして収録しています。

## 起動方法

`index.html` をブラウザで開くだけで利用できます。ローカルサーバーを使う場合は、このフォルダーで次を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 検品の流れ

1. オリコンナンバーを読み取ります。
2. 表示された対象明細を確認します。
3. 商品バーコードを1点ずつ読み取ります。
4. 全商品が予定数と一致したら、オリコンを完了します。

対象外の商品は「品違い」、予定数を超えた商品は「過剰」として記録されます。得意先別の点数とオリコン完了率は、読み取りのたびに更新されます。

## 検証用オリコン

- `10563560` 品番少・数量少
- `10565288` 品番少・数量少
- `10564568` 品番多・数量多
- `10564280` 品番多・数量多
- `10565365` 品番多い
- `10564462` 品番多い
- `10564208` 数量多い
- `10565081` 数量多い

読み取り結果はブラウザのローカルストレージに保存されます。
